# NLP 文本分类任务 (基于 BERT)

本项目是一个基于 PyTorch 和 Hugging Face Transformers 构建的 15 分类中文文本分类模型。

## 💡 项目特点
- **完全解耦的架构**：将数据、模型、训练、配置分离，高度模块化。
- **手写底层逻辑**：没有使用 `BertForSequenceClassification` 和 `Trainer` 等高层封装，而是通过继承 `nn.Module` 手写 BERT + Linear 分类头及 CrossEntropyLoss，更好地控制底层逻辑。
- **多种子实验**：采用 3 个不同的随机种子（42, 66, 99）进行独立训练，避免偶然性。
- **早停机制**：根据验证集表现（Dev Acc）自动保存最优权重，并触发 Early Stopping 防止过拟合。

📊 实验汇报：

一、 整体指标表现

参考指标达成：经过 3 个随机种子（42, 66, 99）的 5 轮独立训练，模型在测试集上的平均准确率达到了 83.65%，且方差较小（± 0.58%），证明模型具备极好的稳定性与泛化能力。

二、 超参数对结果的影响分析（控制变量法）

为了探究不同超参数对模型收敛的具体影响，我保持其他参数不变，分别对学习率（LR）、批次大小（BS）和 Dropout 进行了对比实验：

学习率（Learning Rate）的影响

    lr=1e-5（过小）：平均 Acc 仅 82.17%。收敛极慢，前两轮 Loss 居高不下，模型欠拟合。

    lr=2e-5（基准）：平均 Acc 83.65%。Loss 下降平滑，验证集准确率稳步爬升。

    lr=5e-5（过大）：平均 Acc 82.71%。初期 Loss 震荡剧烈，后期极易陷入局部最优，导致早停提前触发。

    结论：对于 bert-base-chinese，2e-5 是最稳健的学习率区间。

批次大小（Batch Size）的影响

    bs=8：平均 Acc 82.93%。梯度更新次数翻倍，但单次计算的特征较少，导致准确率略微下降，但波动更小。

    bs=16（基准）：平均 Acc 83.65%。

    结论：在显存允许的情况下，16 的批次大小能提供更好的梯度估计质量，精度更高。

正则化（Dropout）的影响

    Dropout=0.1（偏小）：平均 Acc 83.40%。正则化力度不足，第 5 轮 Train Loss 极低（0.14），但 Dev Acc 出现回落，有轻微过拟合。
    
    Dropout=0.3（基准）：平均 Acc 83.65%。完美平衡了拟合能力与泛化能力。
    
    Dropout=0.5（偏大）：平均 Acc 82.99%。正则化过强导致欠拟合，初期 Loss 偏高，且测试集方差极大（± 0.96%）。
    
    结论：0.3 是本任务的最佳 Dropout 阈值。
